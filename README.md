# Cogar C4 / Singer 1501 / ICL 1501

This repository contains information and tooling around the [Cogar C4](https://en.wikipedia.org/wiki/George_Cogar) computer.

[Documentation](documentation) contains know documentation reference.

[Emulator](emulator) contains a work in progress assembler/disassemler/emulator for the machine.

[Hardware](hardware) contains hardware information and reverse engineering.
